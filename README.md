# Personal Expense Tracker

A simple, modern, and beautifully designed web application to track your personal expenses. This project demonstrates core web development concepts including HTML, CSS, JavaScript, CRUD operations, and data persistence using the browser's Local Storage.

## Features

*   **Create**: Add new expenses with descriptions, amounts, categories, and dates.
*   **Read**: View a dynamically updated list of all your past expenses.
*   **Update**: Edit previously added expenses directly from the list.
*   **Delete**: Remove expenses you no longer need.
*   **Data Persistence**: Your expenses are automatically saved to your browser's `localStorage`, meaning they stay there even if you refresh or close the page.
*   **Total Balance**: The total balance is automatically calculated and updated whenever you make changes.
*   **Premium UI**: Features a sleek dark mode interface with glassmorphism effects, responsive design, and smooth hover animations.

## Technologies Used

*   **HTML5**: For the semantic structure of the application.
*   **CSS3**: For the visual styling, including flexbox layouts, gradients, and custom properties (variables).
*   **Vanilla JavaScript (ES6+)**: For handling the logic, form submissions, and DOM manipulation without any external frameworks or libraries.
*   **Google Fonts**: Uses the 'Outfit' font for clean, modern typography.

## How to Run

Because this is a static web application built with vanilla web technologies, you don't need any complex build steps or servers to run it.

1.  Clone or download this repository to your local machine.
2.  Open the folder containing the project files.
3.  Double-click the `index.html` file to open it in your default web browser (Chrome, Firefox, Safari, Edge, etc.).
4.  Start adding your expenses!

## Learning Outcomes

This project is great for beginners looking to understand:
*   How to build forms and handle submit events in JavaScript.
*   How to manipulate the DOM (Document Object Model) to add, remove, or modify HTML elements dynamically.
*   How to work with arrays and objects in JavaScript (using `push`, `filter`, `find`, `reduce`, `sort`, and `map`).
*   How to stringify and parse JSON data to use `localStorage`.
*   How to create modern UI effects like "glassmorphism" using CSS `backdrop-filter`.
